# 救：先建回路，再猜原因

**这一条是整套体系里最省钱的一条。**没有能变红的反馈回路，后面所有动作都是猜。

## 步骤 1：先建一个能变红的回路（这才是重点）

目标是拿到一个**能在这个 bug 上变红、修完变绿**的判定命令。

一条合格的回路必须同时满足：

- [ ] **能红**：跑的是**真实的出错代码路径**，断言的是**用户描述的那个症状**，不是"没崩就算过"
- [ ] **确定性**：每次跑结果一样。飘忽的 bug 要先把复现率提到 90% 以上
- [ ] **快**：秒级，不是分钟级
- [ ] **无人值守可跑**：不依赖人点

按这个顺序试，命中即停：

1. **失败测试**——写在能覆盖到 bug 的那个缝上
2. **curl / HTTP 脚本**——打本地起着的服务
3. **CLI + 固定输入**——对比输出与已知正确的快照
4. **无头浏览器脚本**（Playwright / Puppeteer）——驱动界面、断言 DOM/控制台/网络
5. **回放**：把一次真实的请求/日志/事件存到盘上，离线重放
6. **一次性靶子**：拉起系统最小子集，一个函数调用打穿 bug 路径
7. **性质/模糊测试**：跑 1000 个随机输入，找失败模式
8. **二分**：自动化「启动到状态 X、判定、重复」，让 `git bisect run` 能跑
9. **差分回路**：同一输入走新旧两版，diff 输出
10. **人肉脚本**：最后手段。把人的点击脚本化，循环仍然是结构化的

**拿到之后收紧它**：更快（缓存、跳过无关初始化）、更准（断言具体症状，不只是"没崩"）、更稳（固定随机种子、隔离文件系统、断网）。

> **如果你在回路存在之前就开始读代码编故事，停下。**这正是这个技能要防的事：没有红命令，不许进下一步。

## 步骤 2：复现 + 最小化

跑回路，看它变红。确认：

- [ ] 失败的是**用户说的那个**问题，不是旁边那个。**问题找错，修的就一定错**
- [ ] 多次可复现
- [ ] 症状已捕获（报错文本 / 错误输出 / 耗时）

然后**缩到最小**：输入、调用方、配置、数据、步骤，**一次砍一样**，砍完重跑。
砍到**剩下的每一样都不可或缺**为止（去掉任意一样都会变绿）。

最小复现有两个用途：缩小猜测范围，以及将来变成步骤 5 的回归测试。

## 步骤 3：列 3–5 个可证伪的假设

**先列排序假设，再验证。**只列一个，等于已经锚定在第一个看起来合理的想法上。

每个假设必须能说出预测：

> "如果 X 是原因，那么改动 Y 会让 bug 消失 / 改动 Z 会让它更严重。"

说不出预测的假设是感觉，不是假设。

**把排序列表给用户看一眼再动手。**他们常有能瞬间重排的领域知识（"我们上周刚上线了 #3 相关的东西"）。别停下来等，照你的排序继续。

## 步骤 4：埋点，一次只动一个变量

每个探针对应步骤 3 的一个预测。

1. 调试器 / REPL 断点（环境支持的话）
2. 边界处的定点日志
3. **绝不"全打出来再 grep"**

每个调试日志打**唯一前缀**，例如 `[DEBUG-a4f2]`。收尾时一条 grep 全清掉；没打前缀的日志会活下来。

**性能问题走另一条路**：日志在这时候基本没用。先建基线测量（计时夹具、profiler、查询计划），再二分。**先量，后改。**

## 步骤 5：修 + 回归测试

**先写回归测试，再改代码**——但只在**存在正确缝**的前提下。

正确的缝 = 能复现出**真实 bug 模式**（就像调用点发生的那样）。
缝太浅（单调用方测试但 bug 需要多调用方串联）写出来的回归测试是**假信心**。

**如果没有正确的缝，这本身就是发现。**写下来：代码结构正在阻止这个 bug 被锁死。这条要留作下一阶段处理。

有正确缝的话：

1. 最小复现变成该缝上的失败测试
2. 看它失败
3. 上修复
4. 看它通过
5. 拿步骤 1 的原始回路跑一遍**未最小化**的原始场景，确认好了

## 步骤 6：收尾

- [ ] 原始场景不再复现（重跑步骤 1 的回路）
- [ ] 回归测试通过（或"没有正确缝"已记录在案）
- [ ] 所有 `[DEBUG-...]` 已清除（grep 过）
- [ ] 一次性靶子已删（或明确挪到调试目录）
- [ ] **真正起作用的那个假设写进了提交信息**，让下一个排障的人不用重走一遍

## 附：确实建不出回路时

**明确说出来**，别硬着头皮猜。列出你试过的，然后向用户要：
(a) 一个能复现的环境访问权；(b) 脱敏后的现场材料（HAR、日志转储、core dump、录屏）；(c) 允许你加临时生产埋点。

**没有回路就不许提假设。**这是这个技能唯一不能商量的地方。
